# Ядро інвестиційної агентної системи

Результат сесії **Ради вищого розуму** від 2026-08-12 у режимі FULL (3 раунди, 9 учасників, панель + голова).

**Запит:** розробити AI-агентів, які аналізують ринок ETF, ринок акцій, будують стратегії й оцінюють ризики, з місією, цінностями й цілями, в основі яких — спершу зберегти капітал, і лише потім примножувати. Ядро для передачі агентам розробки та інтеграції.

**Що вийшло:** режим **`parallel-shadow`** — детермінований шар контролю і аналітичні агенти будуються **одночасно**, але агенти мають нуль капіталу і нуль прав виконання, доки не поб'ють виміряну базову лінію. Одноголосно, 9.25 з 9.5 при порозі 6.333, п'ять позицій позначені як DEALBREAKER.
